基于https://github.com/SYSTRAN/faster-whisper 制作的GUI，使用cpu推理，适用于无独显的电脑。

代码中已注明使用简体中文，如需转换英文需修改。

建议使用8代I5及以上CPU，内存大于等于16G.
请将模型放入models文件夹。
